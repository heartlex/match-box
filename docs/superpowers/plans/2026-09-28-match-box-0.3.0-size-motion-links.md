# match-box 0.3.0: size, motion, link buttons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `size` attribute backed by one size scale, token-driven motion in every component, and link buttons (`href`) to the styled components, and document `mb-dialog`'s `show()` and `close()`.

**Architecture:** `tokens.css` gains a size scale (`--mb-size-<s>-*`), dialog widths, and motion tokens that drop to `0ms` under reduced motion. A shared `sizeStyles` maps a `.size-<s>` class to private `--_height`, `--_padding-inline`, `--_font-size`, `--_gap`, and `--_icon`, exactly as `colorRoleStyles` maps `.color-<role>`; components read component tokens that fall back to those. Motion is CSS transitions, `@starting-style`, and one `element.animate()` call in `mb-listbox`; the disclosure panel becomes a grid that animates its rows and hides with `visibility`.

**Tech Stack:** As 0.2 (TypeScript ~6.0, Lit 3, Vitest, `@web/test-runner` with Playwright on Chromium, Firefox, WebKit, Mocha, Chai, axe-core, ESLint, Eleventy 3, TypeDoc, `@custom-elements-manifest/analyzer`). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-28-match-box-v2-step1-followups-design.md` (builds on `docs/superpowers/specs/2026-09-27-match-box-v2-step1-design.md`)

## Global Constraints

- Every commit is authored and committed by `heartlex <gianluca.strada@studio.unibo.it>`; the repo's local git config already sets this. Commit messages carry no `Co-Authored-By` trailer.
- Work happens on `feature/0.3.0-size-motion-links`. There is no `develop` branch; finishing the branch is the finishing-a-development-branch step, not part of any task.
- No new runtime or dev dependencies.
- `size` values: `sm`, `md` (default), `lg`. Unknown values render as `md`. `size`, like `color` and `variant`, is not reflected.
- Components always render an explicit `size-<s>` class, `size-md` included, and never declare component tokens on `:host`.
- Every visual property reads a component token that falls back to a private `--_*` property or a semantic token.
- Motion durations: `--mb-motion-duration-fast` `120ms`, `-medium` `200ms`, `-slow` `300ms`; all `0ms` under `prefers-reduced-motion: reduce`, in themed subtrees too.
- Browser tests run with motion off (`setMotion(false)`, applied by `loadTokens`); only motion tests turn it on.
- Every gate stays green on Chromium, Firefox, and WebKit: `npm run typecheck`, `npm run lint`, `npm run test:unit`, `npm run test:browser`, `npm run size`, `npm run docs`.
- Code style: match the surrounding files — JSDoc on public members, `#private` fields, `declare` for reactive properties with defaults set in the constructor, comments only where the code does not say why.

## Review Focus

1. **Reduced motion inside a themed subtree.** A `[data-theme="light"]` subtree redeclares the semantic block, which would restore non-zero durations; the reduced-motion block must also target `[data-theme]`. Test: Task 1 ("turns every motion duration to 0ms under reduced motion, in themed subtrees too").
2. **A garbage duration or easing token on `mb-listbox`.** `--mb-listbox-duration: fast` or an invalid easing must not throw from `element.animate()`; the option appears unanimated. Test: Task 7 ("an invalid duration or easing adds options without animating or throwing").
3. **Options moved inside a listbox, or loaded after an empty first render.** A moved option must not animate again; options arriving after an empty first render do animate (they were not present at it). Tests: Task 7 ("does not animate an option that is moved", "animates options added after an empty first render").
4. **A link button inside a form.** It must never submit, not on click and not through Enter in a text field of the form, even with `type="submit"`. Test: Task 3 ("Enter in a text field does not submit through a link button").
5. **A disclosure's own `size` inside a sized accordion, and one added later.** The disclosure's attribute wins; a disclosure appended later gets the accordion's size. Test: Task 6 ("gives disclosures its size unless they set their own, including ones added later").

```ts
/** The computed `px` length of a custom property, resolved on a probe element. */
export function resolveLength(token: string, within: Element = document.body): string {
  const probe = document.createElement('div');
  probe.style.width = `var(${token})`;
  within.append(probe);
  const width = getComputedStyle(probe).width;
  probe.remove();
  return width;
}

const noMotion =
  ':root, [data-theme] { --mb-motion-duration-fast: 0ms; --mb-motion-duration-medium: 0ms; --mb-motion-duration-slow: 0ms; }';

/** Turns motion on or off for the page. Off, every transition ends at once, so tests see end states. */
export function setMotion(enabled: boolean): void {
  const existing = document.querySelector('style[data-no-motion]');
  if (enabled) {
    existing?.remove();
    return;
  }
  if (existing) return;
  const style = document.createElement('style');
  style.dataset['noMotion'] = '';
  style.textContent = noMotion;
  document.head.append(style);
}
```

```ts
/** The three sizes. Every size is five tokens in tokens.css. */
export const sizes = ['sm', 'md', 'lg'] as const;

export type Size = (typeof sizes)[number];

/** Returns `value` if it is a size, otherwise `md`. */
export function sizeName(value: string | null | undefined): Size {
  return sizes.find((size) => size === value) ?? 'md';
```

````md
## Sizes

`size` is `sm`, `md` (default), or `lg` on buttons, disclosures,
accordions, and listboxes. Each size is five tokens; retune a size once and
every component follows.

| Token | `sm` | `md` | `lg` |
|---|---|---|---|
| `--mb-size-<s>-height` | 1.75rem | 2.25rem | 2.75rem |
| `--mb-size-<s>-padding-inline` | 0.5rem | 0.75rem | 1rem |
| `--mb-size-<s>-font-size` | 0.875rem | 1rem | 1.125rem |
| `--mb-size-<s>-gap` | 0.25rem | 0.5rem | 0.5rem |
| `--mb-size-<s>-icon` | 0.875rem | 1rem | 1.25rem |

`mb-dialog` sizes its width from `--mb-dialog-width-sm`, `-md`, and `-lg`.

## Motion

Every animation reads these tokens. Under `prefers-reduced-motion: reduce`
every duration is `0ms`.

| Token | Default |
|---|---|
| `--mb-motion-duration-fast` | 120ms |
| `--mb-motion-duration-medium` | 200ms |
| `--mb-motion-duration-slow` | 300ms |
| `--mb-motion-easing-standard`, `-enter`, `-exit`, `-spring` | Curves |

Turn motion off everywhere, for example to drive your own animation
library from the `open` state and the `close` event:

```css
:root {
  --mb-motion-duration-fast: 0ms;
  --mb-motion-duration-medium: 0ms;
  --mb-motion-duration-slow: 0ms;
}
```
````
