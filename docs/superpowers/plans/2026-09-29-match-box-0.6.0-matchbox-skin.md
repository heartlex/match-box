# match-box 0.6.0: matchbox default skin — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the default skin with the matchbox look (palette, type, spacing, sizes, shapes) across every component, ship Geist as the stand-in font, and keep the public API.

**Architecture:** Tokens first. `src/tokens/tokens.css` gets the new primitives and semantic values plus a few new semantic tokens. `colorRoleStyles` exposes two more private role properties. Then each component's `*.styles.ts` changes only where the skin differs in structure. The font ships as an optional `match-box/fonts.css` with a vendored woff2.

**Tech Stack:** Lit 3, TypeScript, CSS custom properties, web-test-runner (Chromium/Firefox/WebKit, chai), vitest, esbuild (size script), Eleventy, Storybook 10.

**Spec:** `docs/superpowers/specs/2026-09-29-match-box-0.6.0-matchbox-skin-design.md`

## Global Constraints

- The public API stays: element names, attributes, properties, events, slots, parts, and every existing `--mb-*` variable name keep working. New variables and parts are additive.
- Tokens: only the semantic tier references primitives. Both dark blocks (`[data-theme='dark']` and the `prefers-color-scheme` copy) stay identical. Every semantic `--mb-color-*` / `--mb-shadow-*` token in the light block appears in both dark blocks.
- Contrast: every text/background pair 4.5:1 and every border/UI mark 3:1, in both themes (checked by `test/browser/tokens.test.ts`).
- Components never declare `--mb-<component>-*` variables on `:host`. Private properties start with `--_`.
- Forced colors, reduced motion, and pinned `line-height` / `letter-spacing` keep working. The page-CSS, forced-colors, reduced-motion and conformance suites stay green without changes to their assertions.
- Sizes: sm / md / lg = 32 / 40 / 48 px (2 / 2.5 / 3rem). Control text 12 / 14 / 16 px.
- Font stack: `'Aeonik', 'Geist', system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif`.
- Budgets: `match-box/components` and `define/all.js` stay at or under 15900 B gzip. `match-box/tokens.css` is raised to its measured size (expected about 2100). `match-box/fonts.css` is 300 B. The woff2 is at most 80 KB.
- Commits: author and committer heartlex (repo-local git config), **no Co-Authored-By trailer**. Never commit `.superpowers/`, `.idea/`, `docs/.DS_Store`.
- `npm version` is blocked by the sandbox: edit version fields in `package.json` and `package-lock.json` directly.
- The full gate is `npm run typecheck && npm run lint && npm test && npm run size`.

## Review Focus

1. **Dark theme under `prefers-color-scheme: dark` with no `data-theme`:** every restyled component must read tokens, not literal light colors. Pinned by a dark-mode check in Tasks 3, 6 and 9 (a literal like `rgb(14 14 48 / 0.4)` is only allowed for the dialog backdrop).
2. **Icon-only button whose text arrives later (or leaves):** the square layout must follow the slot content. Pinned in Task 3.
3. **Switch in RTL at every size:** the new inset math must move the thumb the same distance in both directions. Pinned in Task 7.
4. **A non-neutral `color` on form controls:** `color="danger"` must still drive the accent; only `neutral` borrows primary. Pinned in Tasks 4 and 6.
5. **Forced colors with the new error banner:** the banner must keep a visible boundary and icon. Pinned in Task 5.
